
# Student Course Management System

## Project Information
- Unit: ICTPRG549
- Assessment: Project Stage 1
- Student: Fernando_WKM
- Language: Java
- Interface: Console-based
- IDE: Visual Studio Code

## Features
- Student CRUD operations
- Course CRUD operations
- Search by student ID or course ID
- Course enrolment
- Input validation
- Object-oriented design and encapsulation

## Requirements
- JDK installed
- Visual Studio Code
- Java extensions for VS Code (optional)

## How to Run

Open a terminal in the project root directory.

Compile the source files:

javac -d out src/stage1_Fernando_WKM/*.java

Run the application:

java -cp out stage1_Fernando_WKM.Main

## Data Storage
Student and course records are stored in ArrayList collections.
Records are cleared when the program terminates.
